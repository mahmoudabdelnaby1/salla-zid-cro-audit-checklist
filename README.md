## ⚠️ Known Technical & Domain Constraints

- **Mobile-First Saudi Storefront UX:** Evaluates theme layout against Mada/Apple Pay express checkout placement, product image zoom, and delivery estimate badges.
- **Platform App Bloat Audit:** Identifies third-party JS apps and tracking pixels that degrade Core Web Vitals and slow mobile checkout loading.
- **Address Capture Optimization:** Ensures integration with Saudi National Address lookup to minimize address input errors.
